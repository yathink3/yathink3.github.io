# Yathin K — Staff Engineer & Frontend Architect Portfolio

A hardcore developer portfolio website built with **TanStack Start**, **Vite 8**, **Tailwind CSS v4**, **React 19**, and **Nitro SSR**, inspired by high-octane engineering aesthetics (interactive terminals, ambient particle networks, CRT scanlines, and bento architectures).

---

## ⚡ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) with [TanStack Router](https://tanstack.com/router)
- **Bundler & Engine**: [Vite 8](https://vite.dev/) (Native TSConfig paths & sub-second builds)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Engine**: React 19
- **SSR Server**: Nitro (`nitro/vite`)
- **Typography**: Space Grotesk (sans), Instrument Serif (editorial italic), JetBrains Mono (terminal code)
- **Icons**: Lucide Icons & Custom SVG glyphs

---

## 🚀 Quick Start

### Prerequisites
- Node.js 20+ or Bun 1.2+

### Development
```bash
cd projects/portfolio
bun install
bun run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build & Preview
```bash
bun run build
bun run start
```
